# Source files

The repository includes local copies of the statistical workbooks supplied with the project under `data/source/`.

| Repository file | Original role |
|---|---|
| `population_by_year.xlsx` | Population denominators |
| `deaths_by_year.xlsx` | Registered deaths |
| `cancer_morbidity.xls` | Malignant neoplasm morbidity |
| `infant_mortality.xls` | Infant mortality |
| `circulatory_morbidity.xlsx` | Circulatory-disease morbidity |
| `registered_disability.xlsx` | Registered disability |
| `unemployment.xlsx` | Unemployment |
| `legacy_PCA_clean_results.xlsx` | Legacy processed PCA workbook retained for provenance only |
| `legacy_all_regions_processed.xlsx` | Legacy combined processed table retained for provenance only |

Metadata in the supplied files identifies the Bureau of National Statistics of the Republic of Kazakhstan as the source for multiple series.

Known public metadata links used in the manuscript:

- Population: https://stat.gov.kz/en/open-data/demography/476538/
- Deaths: https://stat.gov.kz/en/open-data/demography/476540/
- Unemployment: https://stat.gov.kz/en/open-data/labor-statistics/476575/
- Disability dynamic tables: https://stat.gov.kz/en/industries/social-statistics/stat-medicine/dynamic-tables/

Before journal submission, archive download dates and exact URLs for every morbidity workbook.
