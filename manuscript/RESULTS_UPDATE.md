# Results update for the manuscript

The previous Word draft should **not** be treated as numerically final because the exposed-only mortality series was corrected during repository preparation.

Use the following RQ2 results in the next manuscript revision:

- N = 42 exposed-region-year observations.
- Overall KMO = 0.5099.
- Bartlett chi-square(10) = 75.5632, p < 0.001 under the conventional reference distribution.
- PC1 explained variance = 49.18%.
- PC2 explained variance = 26.03%.
- PC1 + PC2 cumulative explained variance = 75.21%.

Original-indicator OLS model:

- R-squared = 0.3112
- Adjusted R-squared = 0.1443
- RMSE = 0.0887
- AIC = -66.27
- BIC = -50.63

PCA-reduced OLS model:

- R-squared = 0.2639
- Adjusted R-squared = 0.1617
- RMSE = 0.0917
- AIC = -69.48
- BIC = -59.05

Suggested interpretation:

> In the exposed-only analysis, PC1 and PC2 retained 75.21% of standardized predictor variance. The original-indicator model achieved higher in-sample R-squared and lower RMSE, while the PCA-reduced model achieved slightly higher adjusted R-squared and lower AIC/BIC, reflecting a trade-off between raw in-sample fit and parsimony. Because the analysis contains only three repeatedly observed geographic regions, coefficient-level inference remains exploratory.
